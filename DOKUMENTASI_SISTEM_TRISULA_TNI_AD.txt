1.   Umum.
     a.   Dokumentasi sistem merupakan salah satu kegiatan fundamental dalam
          penyelenggaraan pembinaan sistem informasi di lingkungan TNI AD pada
          setiap tahapan daur hidup pembangunan sistem perangkat lunak.
          Dokumentasi sistem dibuat secara kolaboratif oleh Analis Sistem dan
          Pemrogram, selanjutnya dihimpun menjadi satu berkas terstruktur yang
          menjadi tanggung jawab resmi Pemrogram guna menjamin transparansi,
          akuntabilitas, dan keterpeliharaan sistem.

     b.   Prajurit dan Pegawai Negeri Sipil (PNS) TNI Angkatan Darat dalam
          pelaksanaan tugas dinas keprajuritan memiliki 33 (tiga puluh tiga)
          jenis warkat induk administrasi atau dosir wajib. Selama ini, tata
          kelola dosir fisik menghadapi kerentanan risiko kerusakan fisik akibat
          usia kertas, kelembapan, bencana alam, serta lambatnya proses pencarian
          berkas saat pengusulan kenaikan pangkat (UKP), penugasan operasi,
          maupun persiapan masa purna tugas.

     c.   Guna mengatasi kendala kearsipan tersebut, dibangun sistem TRISULA
          TNI AD (Tata Kelola Rekam Informasi, Sistematika, & Unduhan Lengkap

          pemindaian langsung melalui kamera gawai, menerapkan verifikasi
          administratif bertingkat oleh Staf Personel, serta mengesahkan warkat
          melalui Tanda Tangan Elektronik (TTE) ber-QR Code dengan verifikasi
          integritas cryptographic hash SHA-256.

     d.   Agar operasional, pemeliharaan (har), pengawasan, dan pengembangan
          aplikasi TRISULA TNI AD dapat berjalan secara berkelanjutan dan
          berdaya guna, maka disusun Buku Dokumentasi Sistem ini dengan mengacu

10.  Narasi Program.
     a.   Fungsi Program.
          Aplikasi TRISULA TNI AD menyelenggarakan 12 fungsi kunci:
          1)  Pendaftaran akun mandiri personel berbasis NRP dengan approval admin.
          2)  Tata kelola 33 jenis dosir baku prajurit/PNS TNI AD.
          3)  Penamaan file otomatis {NRP}_{KODE}[abjad].pdf dan folder FOLDER 01..33.
          4)  Pemindaian warkat lewat kamera (camera scan) terintegrasi jsPDF.
          5)  Verifikasi bertingkat dengan TTE ber-QR Code dan watermark resmi.
          6)  Portal publik verifikasi keabsahan dokumen ber-QR Code (verify.php).
          7)  Pemantauan kelengkapan dosir personel dan rata-rata satuan.
          8)  Kalkulasi batas usia pensiun: Perwira 58 th, Bintara/Tamtama 56 th, PNS 60 th.
          9)  Deteksi otomatis prajurit dengan masa jabatan > 2 tahun (TOD/TOA).
          10) Unduh massal berkas terstruktur per satuan/personel dalam arsip ZIP.
          11) Laporan resmi siap cetak berkop dinas staf personel & tanda tangan komando.
          12) Pencadangan basis data & berkas serta pencatatan log audit trail.

     b.   Input Program.
+----+----------------------+--------------------+---------------+---------------------------------------------------------+
| NO | NAMA FILE / TABEL    | MEDIA PENYIMPANAN  | RECORD LENGTH | KETERANGAN / FUNGSI MASUKAN                             |
+----+----------------------+--------------------+---------------+---------------------------------------------------------+
| 1. | personel             | Harddisk (MySQL DB)| 1.250 Byte    | Data pokok prajurit (NRP, Nama, Pangkat, Satuan, TMT)  |
| 2. | users                | Harddisk (MySQL DB)| 420 Byte      | Kredensial login, hash password bcrypt, peran otoritas  |
| 3. | dosir_master         | Harddisk (MySQL DB)| 240 Byte      | Master referensi baku 33 jenis dosir TNI AD             |
| 4. | dosir_files          | Harddisk (MySQL DB)| 980 Byte      | Metadata dosir terunggah, kode TTE, hash SHA-256        |
| 5. | uploads/FOLDER 01..33| Harddisk (Storage) | s.d. 10 MB    | Berkas digital PDF warkat dosir prajurit                |
| 6. | settings             | Harddisk (MySQL DB)| 280 Byte      | Parameter identitas, brand, logo, dan batas jabatan     |
| 7. | activity_log         | Harddisk (MySQL DB)| 360 Byte      | Catatan audit trail seluruh aktivitas mutasi sistem     |
| 8. | login_attempts       | Harddisk (MySQL DB)| 160 Byte      | Log keamanan percobaan login untuk anti brute-force     |
+----+----------------------+--------------------+---------------+---------------------------------------------------------+

     c.   Proses Pengolahan.
          1)  Registrasi: Personel mendaftar mandiri. Sistem memvalidasi format
              NRP, menyimpan data induk di tabel personel, dan membuatkan akun
              di tabel users dengan status 'pending'.
          2)  Approval Akun: Administrator memeriksa kebenaran identitas prajurit
              lalu menyetujui akun sehingga personel dapat masuk ke sistem.
          3)  Unggah & Scan: Personel memilih kode jenis dosir. Berkas diunggah
              dalam format PDF atau dipindai via kamera (jsPDF). Sistem memvalidasi
              MIME type dan ukuran file (maks 10 MB). Berkas master asli disimpan
              pada raw_file_path.
          4)  Penamaan Otomatis: Berkas pertama diberi nama {NRP}_{KODE}.pdf.
              Berkas kedua dst pada slot yang sama diberi indeks abjad otomatis
              {NRP}_{KODE}a.pdf, {NRP}_{KODE}b.pdf, dst. File disimpan dalam
              subdirektori terisolasi uploads/FOLDER {kode}/.
          5)  Watermark Sementara: Berkas berstatus pending diberi watermark
              peringatan "PENDING APPROVAL - BELUM DIVERIFIKASI".
          6)  Verifikasi & Penerbitan TTE: Saat Admin menyetujui berkas:
              - Berkas master bersih diambil (watermark pending hilang permanen).
              - Checksum SHA-256 dihitung sebagai segel integritas dokumen.
              - Nomor registrasi unik TTE-TRISULA-{YYYYMM}-{ID}-{TOKEN} digenerate.
              - Pustaka FPDI + TCPDF menyematkan running header pada seluruh halaman
                dan membubuhkan kotak stempel TTE ber-QR Code di halaman terakhir.
              - Status berkas diubah menjadi 'approved'.
          7)  Analitik: Menghitung persentase kelengkapan (Approved / 33 * 100%),
              menghitung selisih TMT jabatan terhadap tanggal berjalan (> 2 tahun),
              dan memproyeksikan TMT pensiun berdasarkan tanggal lahir & golongan.
          8)  Laporan & Unduh Massal: Mengompilasi data ke format cetak kedinasan
              dan mengompresi berkas terverifikasi ke dalam arsip ZIP terstruktur.

     d.   Output Program.
          1)  Keluaran Display Layar:
              - Dashboard Personel: Status verifikasi 33 dosir & progress bar.
              - Dashboard Admin: Rekapitulasi satuan, daftar tunggu verifikasi,
                kandidat rotasi jabatan > 2 tahun, dan proyeksi pensiun.
              - Halaman Verifikasi TTE Publik (verify.php): Informasi keabsahan
                dokumen digital saat QR Code dipindai oleh pemeriksa.
          2)  Keluaran Cetakan & Berkas Digital:
              - Dokumen PDF Ber-TTE Resmi (stempel digital dinas & QR Code).
              - Laporan Resmi Rekapitulasi Kelengkapan Dosir Satuan (Kop Spers).
              - Laporan Proyeksi Pensiun Prajurit/PNS Satuan.
              - Laporan Masa Jabatan Personel (> 2 Tahun).
              - Arsip ZIP Hasil Unduh Massal (Bulk Download).

     Penjelasan Kardinalitas & Integritas Relasi Alami :
     1. PERSONEL (1) <---> (1) USERS : Setiap prajurit/PNS hanya memiliki 1 akun login
        (diikat oleh konstrain UNIQUE pada users.personel_id).
     2. PERSONEL (1) <---> (N) DOSIR_FILES : Satu personel memiliki banyak berkas dosir.
        Kaskade: ON DELETE CASCADE (jika personel dihapus, dosir ikut terhapus).
     3. DOSIR_MASTER (1) <---> (N) DOSIR_FILES : Berkas dosir merujuk ke 33 jenis baku.
        Integritas: ON DELETE RESTRICT ON UPDATE CASCADE.
     4. USERS (1) <---> (N) DOSIR_FILES (uploaded_by) : Mencatat user pengunggah.
     5. USERS (1) <---> (N) DOSIR_FILES (verified_by) : Mencatat user admin verifikator TTE.
     6. USERS (1) <---> (N) ACTIVITY_LOG (user_id) : Mencatat user pelaku aksi audit trail.
     7. USERS (1) <---> (N) BACKUP_LOG (created_by) : Mencatat user pembuat backup data.

function apply_digital_signature_pdf($rawMasterPath, $outputPath, array $signData) {
    if (!class_exists('\setasign\Fpdi\Tcpdf\Fpdi')) return false;
    $source = file_exists($rawMasterPath) ? $rawMasterPath : $outputPath;
    if (!file_exists($source)) return false;

    try {
        $pdf = new \setasign\Fpdi\Tcpdf\Fpdi();
        $pdf->setPrintHeader(false);
        $pdf->setPrintFooter(false);
        $pdf->SetMargins(0, 0, 0);
        $pdf->SetAutoPageBreak(false, 0);

        $pageCount = $pdf->setSourceFile($source);
        $code      = $signData['code'];
        $verifyUrl = $signData['verify_url'];
        $signDate  = $signData['date'] ?? date('d-m-Y H:i:s');
        $docHash   = $signData['hash'] ?? hash_file('sha256', $source);
        $shortHash = substr($docHash, 0, 16) . '...' . substr($docHash, -8);

        for ($i = 1; $i <= $pageCount; $i++) {
            $tplId = $pdf->importPage($i);
            $size  = $pdf->getTemplateSize($tplId);
            $orientation = $size['width'] > $size['height'] ? 'L' : 'P';
            $pdf->AddPage($orientation, [$size['width'], $size['height']]);
            $pdf->useTemplate($tplId);
            $w = $size['width'];
            $h = $size['height'];

            // 1. Running Header Autentikasi Pada Seluruh Halaman
            $pdf->SetAlpha(1.0);
            $pdf->SetFont('helvetica', '', 6.5);
            $pdf->SetTextColor(70, 95, 75);
            $runningLine = "E-DOSIR TNI AD - DITANDATANGANI SECARA ELEKTRONIK (TTE) | KODE: $code | HASH: $shortHash | $signDate WIB";
            $pdf->SetXY(6, $h - 6.5);
            $pdf->Cell($w - 12, 4, $runningLine, 0, 0, 'L');

            // 2. Kotak Tanda Tangan Digital Resmi Pada Halaman Terakhir
            if ($i === $pageCount) {
                $boxW = 88; $boxH = 38;
                $boxX = $w - $boxW - 8;
                $boxY = $h - $boxH - 9;
                if ($boxY < 8) $boxY = 8;
                if ($boxX < 8) $boxX = 8;

                $pdf->SetFillColor(255, 255, 255);
                $pdf->SetDrawColor(46, 85, 52);
                $pdf->Rect($boxX, $boxY, $boxW, $boxH, 'DF');

                // Render Barcode QR Code Dinamis
                $styleQr = ['border' => 0, 'padding' => 1, 'fgcolor' => [30, 60, 35], 'bgcolor' => [255, 255, 255]];
                $pdf->write2DBarcode($verifyUrl, 'QRCODE,L', $boxX + 2.5, $boxY + 4, 25, 25, $styleQr, 'N');

                // Informasi TTE Resmi
                $pdf->SetFont('helvetica', 'B', 7);
                $pdf->SetTextColor(35, 70, 40);
                $pdf->SetXY($boxX + 29, $boxY + 3.5);
                $pdf->Cell(56, 3.5, 'DITANDATANGANI SECARA ELEKTRONIK', 0, 1, 'L');

                $pdf->SetFont('helvetica', '', 6.2);
                $pdf->SetXY($boxX + 29, $boxY + 16.8);
                $pdf->Cell(56, 3.2, $signData['pangkat_admin'] . ' NRP ' . $signData['nrp_admin'], 0, 1, 'L');

                $pdf->SetXY($boxX + 29, $boxY + 20);
                $pdf->Cell(56, 3.2, $signData['satuan_admin'], 0, 1, 'L');
            }
        }

        $tmp = $outputPath . '.tmp';
        $pdf->Output($tmp, 'F');
        if (file_exists($tmp)) {
            rename($tmp, $outputPath);
            return true;
        }
        return false;
    } catch (\Throwable $e) {
        error_log('TTE Error: ' . $e->getMessage());
        return false;
    }
}

/**
 * Menghitung Proyeksi Tanggal Pensiun Sesuai Golongan
 * Batas Usia Pensiun (BUP): Perwira 58 th, Bintara/Tamtama 56 th, PNS 60 th
 */
function hitung_proyeksi_pensiun(?string $tanggalLahir, string $golongan): ?string {
    if (!$tanggalLahir) return null;
    $usiaPensiun = USIA_PENSIUN[$golongan] ?? 56;
    try {
        $tgl = new DateTime($tanggalLahir);
        $tgl->modify("+{$usiaPensiun} years");
        $tgl->modify('first day of next month');
        return $tgl->format('Y-m-d');
    } catch (Exception $e) {
        return null;
    }
}

/**
 * Deteksi Masa Jabatan Melebihi Batas Tertentu (Baku: 2 Tahun)
 * Mendukung Perencanaan Mutasi / Tour of Duty & Tour of Area (TOD/TOA)
 */
function is_jabatan_melebihi_batas(?string $tmtJabatan, int $batasTahun = 2): bool {
    if (!$tmtJabatan) return false;
    try {
        $tmt = new DateTime($tmtJabatan);
        $sekarang = new DateTime();
        $interval = $tmt->diff($sekarang);
        return ($interval->y >= $batasTahun && !$interval->invert);
    } catch (Exception $e) {
        return false;
    }
}
